# 아리채 오락실

버튼 세 개(빨강·초록·파랑)로 온 가족이 각자 폰·태블릿에서 동시에 겨루는 미니게임 모음입니다.
서버는 **Render(클라우드)**에서 돌아가고, 가족은 카톡으로 받은 링크를 눌러 어디서든 들어옵니다.
파이썬 기본 기능만 써서 **추가로 설치할 부품이 없어요.**

---

## A. Render에 올리기 (처음 한 번만)

준비물: GitHub 계정, Render 계정(GitHub로 로그인 가능), 결제 카드(월 7달러)

### 1) GitHub에 코드 올리기
1. https://github.com 로그인 → 오른쪽 위 **+** → **New repository**
2. 이름 `arichae-arcade`, **Private** 선택 → **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 링크 클릭
4. 압축을 푼 `arichae_arcade` 폴더 **안의 내용물 전체**(server.py, render.yaml, static 폴더 등)를 끌어다 놓기
   - `server.py`와 `render.yaml`이 저장소 맨 위에 보여야 해요 (폴더 한 겹 안에 들어가면 안 돼요)
5. 아래 **Commit changes**

### 2) Render에서 서버 만들기
1. https://render.com → **Get Started** → **GitHub로 로그인**
2. 오른쪽 위 **+ New** → **Blueprint**
3. GitHub 연결 화면에서 `arichae-arcade` 저장소 접근 허용 → 저장소 선택
4. `render.yaml`을 읽어서 `arichae-arcade` 서비스가 보이면 **Deploy Blueprint**
   - 지역 싱가포르, 사양 `0.5c-512mb`(월 7달러, 항상 켜짐)로 자동 설정돼요
5. 카드 정보 입력 → 1~2분 뒤 상태가 **Live**가 되면 완료
6. 서비스 화면 위쪽의 주소(`https://arichae-arcade-xxxx.onrender.com`)가 우리 오락실 주소예요

### 새 버전으로 바꿀 때
GitHub 저장소에서 **Add file → Upload files**로 바뀐 파일을 다시 올리고 **Commit changes** 하면
Render가 알아서 새 버전으로 다시 켜요(1~2분). 그동안 하던 방은 끊기니 게임 중이 아닐 때 올려 주세요.

## B. 노트북에서 시험해 보기 (선택)

1. 파이썬 설치 (https://www.python.org, 설치 화면에서 **"Add python.exe to PATH"** 체크)
2. `run.bat` 더블클릭
3. 브라우저에서 `http://localhost:8000` 접속

## 방 만들고 가족 초대하기

1. Render 주소로 접속 (홈 화면에 추가해 두면 앱처럼 쓸 수 있어요)
2. 이름 쓰고 동물 캐릭터 고른 뒤 **방 만들기**
3. 대기실에서 **초대 링크 보내기** → 카톡 대화방에 붙여넣기
4. 가족이 링크를 누르면 캐릭터 고르는 화면이 바로 열려요
5. 모두 들어오면 방장이 **시작하기**

와이파이가 달라도, 집 밖에 있어도 인터넷만 되면 같이 할 수 있어요.

### 앱으로 설치 (누구나 방장)
첫 화면 오른쪽 위 **앱 설치** 버튼을 누르면 홈 화면에 아리채 오락실 아이콘이 생겨요.
누구나 그 아이콘으로 열어서 **방 만들기**를 누르면 방장이 돼요.
- 안드로이드 크롬: 버튼을 누르면 바로 설치 창이 떠요
- 아이폰: Safari 공유 버튼 → 홈 화면에 추가
- 카톡에서 링크를 열면 자동으로 기본 브라우저(크롬·사파리)로 다시 열려요

### 과학관 모드 (골라서 배우는 게임)

대기실에서 방장이 **오락실 / 과학관**을 고를 수 있어요. 과학관은 랜덤이 아니라 방장이 게임을 골라 **누른 순서대로** 진행하고,
난이도(초등·중등·고등)도 방장이 정해요. 그 게임에 없는 난이도면 가장 가까운 단계로 해요. 게임이 끝나면 **오늘 배운 것** 카드가 나와요.

| 전시관 | 게임 | 난이도 | 방법 |
|---|---|---|---|
| 빛의 방 | 빛 섞기 | 초·중 | 빨강·초록·파랑 빛을 켜고 꺼서 목표 색 만들기 (중: 가이드 표) |
| 물감 공방 | 물감 섞기 | 초·중 | 버튼이 물감으로 바뀜. 필요한 물감만 넣기 (초: 빨노파, 중: 청록·자홍·노랑) |
| 시간 여행관 | 지구 역사 순서 | 중 | 사건 3개를 오래된 순서로, 24시간 시계로 정답 확인 |
| 바다관 | 바다 낚시 | 초·중 | 미션 동물만 낚기 (초: 물고기만, 중: 무리가 바뀜) |
| 우주관 | 행성 찾기 | 초·중 | 초: 그림·힌트로 행성 이름 / 중: 태양에서 가까운 순서 |
| 생명의 나무 | 진화 나무 오르기 | 초·중 | 동물을 맞는 무리 가지로 보내며 나무 오르기 |
| 원소관 | 주기율표 빨리 고르기 | 초·중·고 | 원소 이름↔기호, 원자번호, 같은 족 찾기 (힌트 제공, 힌트 전에 맞히면 +20) |

### 음악관 모드 (골라서 연주하는 클래식)

방장이 곡을 골라 누른 순서대로 연주해요. 한 곡에 약 1분 30초(주제 → 변주).
난이도 **하**(보통 빠르기, 변주에서 음표 두 배) · **중**(조금 빠르게, 높은 소리로 음표 두 배) · **상**(처음부터 음표 두 배 + 마디마다 두 줄을 같이 누르는 화음 음표) · **특상**(더 빠르게, 음표가 더 빨리 떨어지고 화음이 마디마다 두 번, 비발디는 원곡 16분음표 리듬 그대로).
빠른 난이도에서 곡이 일찍 끝나면 주제를 한 번 더 연주하는 '피날레'가 붙어요.
곡: 작은 별 변주곡(모차르트), 환희의 송가(베토벤), 미뉴에트 G장조(바흐), 엘리제를 위하여(베토벤), 자장가(브람스),
사계 봄 1악장 · 여름 3악장 · 가을 1악장 · 겨울 2악장(비발디 — [Mutopia Project](https://www.mutopiaproject.org/) 공개 악보의 독주 바이올린 선율)
끝나면 그 곡에 얽힌 이야기가 나와요.

### 오락실 모드

- 한 판은 3게임(짧게) / 5게임(보통) / 10게임(길게) 중 방장이 고릅니다.
- 카드 덱처럼 섞어서, 17개 게임이 한 바퀴 다 나오기 전에는 같은 게임이 다시 나오지 않아요.
- 미니게임마다 순위대로 100·80·65·50·40·30·20·10점을 받고, 합계로 최종 우승을 가립니다.
- 모두 같은 문제(같은 블록 순서, 같은 신호)로 동시에 시작해서 공정해요.
- 한 방 최대 8명.

## 알아두면 좋은 것

- **소리**: 입장 버튼을 누를 때 켜져요. 아이폰은 무음 스위치가 켜져 있으면 소리가 안 나요.
- **진동**: 안드로이드에서만 돼요. 대기실 위쪽 버튼으로 끄고 켤 수 있어요.
- **PC 키보드**: `A`/`S`/`D`, `J`/`K`/`L`, 또는 `1`/`2`/`3`
- **연결이 끊겨도** 자동으로 다시 들어오고, 새로고침해도 같은 방으로 돌아와요.
- 게임 도중 들어온 사람은 그 게임은 구경하고 다음 게임부터 참여해요.
- 방장이 20초 넘게 끊기면 다른 사람이 방장이 돼요.

## 폴더 구조

```
arichae_arcade/
├─ server.py              게임 서버 (파이썬 기본 기능만 사용)
├─ render.yaml            Render 배포 설정
├─ run.bat                윈도우 노트북에서 시험용 실행 파일
└─ static/
   ├─ games.json          ★ 게임 목록·플레이 시간·음악관 곡 순서 (서버와 화면이 같이 읽어요)
   ├─ index.html          화면 뼈대 (스크립트 목록은 서버가 games.json 보고 자동으로 넣어요)
   ├─ css/style.css       디자인
   └─ js/
      ├─ app.js           화면 흐름·서버 연결·버튼 입력
      ├─ kit.js           게임 공통 도구 + 게임 등록부(G.register)
      ├─ animals.js       동물 캐릭터 20종
      ├─ audio.js         효과음·배경음악·진동
      ├─ data/            내용 데이터 (songs.js 노래 악보, creatures.js 바다 생물)
      └─ games/
         ├─ arcade/       오락실 미니게임 — 게임 하나당 파일 하나 (blocks.js, race.js …)
         └─ edu/          과학관·음악관 게임 (light.js, music.js …)
```

## 게임·내용 추가하는 법

**오락실 미니게임 하나 더**
1. `static/js/games/arcade/<id>.js` 를 만들어요 (비슷한 게임 파일을 복사해서 시작하면 편해요).
   파일 끝에서 `G.register(게임)` 으로 등록하고, 공통 도구는 `const { rng, el, HEX … } = G.kit;` 로 꺼내 써요.
2. `static/games.json` 의 `"arcade"` 에 `{ "id": "<id>", "dur": 30, "name": "게임 이름" }` 한 줄 추가.
3. 끝. 서버 수정, `index.html` 수정, `?v=` 버전 올리기 모두 필요 없어요 (서버가 파일 내용으로 버전을 붙여요).

**과학관 게임 하나 더** — 위와 같고 폴더만 `games/edu/`, 목록은 `"edu"`. 게임 정의에 `edu: true`, `levels`, `hall` 을 넣어요.

**음악관 곡 하나 더** — `js/data/songs.js` 의 `HALL` 에 곡을 넣고 `games.json` 의 `"songs"` 에 id 추가.
저작권이 끝난 곡(작곡가 사후 70년 지난 클래식, 옛 동요)만 넣어요.

**새 데이터 파일** (문제 은행, 연표 등) — `js/data/` 에 만들고 `games.json` 의 `scripts.before` 에 경로 추가.

게임은 모두 서버가 준 같은 `seed` 로 같은 문제를 만들어야 해요 (`Math.random` 대신 `rng(ctx.seed)`).

## 설정 (환경변수, 선택)

| 이름 | 설명 | 기본값 |
|---|---|---|
| `PORT` | 서버 포트 (Render가 자동 지정) | 8000 |
