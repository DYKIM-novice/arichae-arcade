# 아리채 오락실

버튼 세 개(빨강·초록·파랑)로 온 가족이 각자 폰·태블릿에서 동시에 겨루는 미니게임 모음입니다.
서버는 **Render(클라우드)**에서 돌아가고, 가족은 카톡으로 받은 링크를 눌러 어디서든 들어옵니다.
파이썬 기본 기능만 써서 **추가로 설치할 부품이 없어요.**

---

## A. Render에 올리기 (처음 한 번만)

준비물: GitHub 계정, Render 계정(GitHub로 로그인 가능), 결제 카드(월 7달러)

### 1) GitHub에 코드 올리기
1. https://github.com 로그인 → 오른쪽 위 **+** → **New repository**
2. 이름 `arichae-arcade`, **Private** 선택 → **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 링크 클릭
4. 압축을 푼 `arichae_arcade` 폴더 **안의 내용물 전체**(server.py, render.yaml, static 폴더 등)를 끌어다 놓기
   - `server.py`와 `render.yaml`이 저장소 맨 위에 보여야 해요 (폴더 한 겹 안에 들어가면 안 돼요)
5. 아래 **Commit changes**

### 2) Render에서 서버 만들기
1. https://render.com → **Get Started** → **GitHub로 로그인**
2. 오른쪽 위 **+ New** → **Blueprint**
3. GitHub 연결 화면에서 `arichae-arcade` 저장소 접근 허용 → 저장소 선택
4. `render.yaml`을 읽어서 `arichae-arcade` 서비스가 보이면 **Deploy Blueprint**
   - 지역 싱가포르, 사양 `0.5c-512mb`(월 7달러, 항상 켜짐)로 자동 설정돼요
5. 카드 정보 입력 → 1~2분 뒤 상태가 **Live**가 되면 완료
6. 서비스 화면 위쪽의 주소(`https://arichae-arcade-xxxx.onrender.com`)가 우리 오락실 주소예요

### 새 버전으로 바꿀 때
GitHub 저장소에서 **Add file → Upload files**로 바뀐 파일을 다시 올리고 **Commit changes** 하면
Render가 알아서 새 버전으로 다시 켜요(1~2분). 그동안 하던 방은 끊기니 게임 중이 아닐 때 올려 주세요.

## B. 노트북에서 시험해 보기 (선택)

1. 파이썬 설치 (https://www.python.org, 설치 화면에서 **"Add python.exe to PATH"** 체크)
2. `run.bat` 더블클릭
3. 브라우저에서 `http://localhost:8000` 접속

## 방 만들고 가족 초대하기

1. Render 주소로 접속 (홈 화면에 추가해 두면 앱처럼 쓸 수 있어요)
2. 이름 쓰고 동물 캐릭터 고른 뒤 **방 만들기**
3. 대기실에서 **초대 링크 보내기** → 카톡 대화방에 붙여넣기
4. 가족이 링크를 누르면 캐릭터 고르는 화면이 바로 열려요
5. 모두 들어오면 방장이 **시작하기**

와이파이가 달라도, 집 밖에 있어도 인터넷만 되면 같이 할 수 있어요.

### 앱으로 설치 (누구나 방장)
첫 화면 오른쪽 위 **앱 설치** 버튼을 누르면 홈 화면에 아리채 오락실 아이콘이 생겨요.
누구나 그 아이콘으로 열어서 **방 만들기**를 누르면 방장이 돼요.
- 안드로이드 크롬: 버튼을 누르면 바로 설치 창이 떠요
- 아이폰: Safari 공유 버튼 → 홈 화면에 추가
- 카톡에서 링크를 열면 자동으로 기본 브라우저(크롬·사파리)로 다시 열려요

### 과학관 모드 (골라서 배우는 게임)

대기실에서 방장이 **오락실 / 과학관**을 고를 수 있어요. 과학관은 랜덤이 아니라 방장이 게임을 골라 **누른 순서대로** 진행하고,
난이도(초등·중등·고등)도 방장이 정해요. 그 게임에 없는 난이도면 가장 가까운 단계로 해요. 게임이 끝나면 **오늘 배운 것** 카드가 나와요.

| 전시관 | 게임 | 난이도 | 방법 |
|---|---|---|---|
| 빛의 방 | 빛 섞기 | 초·중 | 빨강·초록·파랑 빛을 켜고 꺼서 목표 색 만들기 (중: 가이드 표) |
| 물감 공방 | 물감 섞기 | 초·중 | 버튼이 물감으로 바뀜. 필요한 물감만 넣기 (초: 빨노파, 중: 청록·자홍·노랑) |
| 시간 여행관 | 지구 역사 순서 | 중 | 사건 3개를 오래된 순서로, 24시간 시계로 정답 확인 |
| 바다관 | 바다 낚시 | 초·중 | 미션 동물만 낚기 (초: 물고기만, 중: 무리가 바뀜) |
| 우주관 | 행성 찾기 | 초·중 | 초: 그림·힌트로 행성 이름 / 중: 태양에서 가까운 순서 |
| 생명의 나무 | 진화 나무 오르기 | 초·중 | 동물을 맞는 무리 가지로 보내며 나무 오르기 |
| 원소관 | 주기율표 빨리 고르기 | 초·중·고 | 원소 이름↔기호, 원자번호, 같은 족 찾기 (힌트 제공, 힌트 전에 맞히면 +20) |

### 음악관 모드 (골라서 연주하는 클래식)

방장이 곡을 골라 누른 순서대로 연주해요. 한 곡에 약 1분 30초(주제 → 변주).
난이도 **하**(보통 빠르기, 변주에서 음표 두 배) · **중**(조금 빠르게, 높은 소리로 음표 두 배) · **상**(처음부터 음표 두 배 + 마디마다 두 줄을 같이 누르는 화음 음표) · **특상**(더 빠르게, 음표가 더 빨리 떨어지고 화음이 마디마다 두 번, 비발디는 원곡 16분음표 리듬 그대로).
빠른 난이도에서 곡이 일찍 끝나면 주제를 한 번 더 연주하는 '피날레'가 붙어요.
곡: 작은 별 변주곡(모차르트), 환희의 송가(베토벤), 미뉴에트 G장조(바흐), 엘리제를 위하여(베토벤), 자장가(브람스),
사계 봄 1악장 · 여름 3악장 · 가을 1악장 · 겨울 2악장(비발디 — [Mutopia Project](https://www.mutopiaproject.org/) 공개 악보의 독주 바이올린 선율)
끝나면 그 곡에 얽힌 이야기가 나와요.

### 보드게임관 (AI 대결 · 사람끼리 1:1)

대기실에서 **보드게임** 을 고르고, **AI와 대결**(1~5단계: 병아리·토끼·여우·호랑이·용) 또는 **사람끼리 1:1** 을 골라요.
나머지 사람은 구경할 수 있어요. AI 는 방장 폰에서 계산해요 (화면이 멈추지 않게 따로 돌아요).
- **오목**: 15줄 판, 3·3 금지(흑·백 모두, 띈 3·3·3·3 포함, ✕ 표시로 못 둠), 4·4 허용, 6목은 승리 아님
- 놓을 자리를 한 번 누르면 미리 보이고, 한 번 더 누르거나 [여기에 두기] 로 확정
- AI 대결에서는 **무르기**, **힌트**(AI 4단계가 추천)를 쓸 수 있어요 — 쓰면 그 판은 기록에 안 남아요
- **📜 규칙 보기**: 대기실의 [규칙 보기] 또는 대국 화면 위쪽 📜 버튼 — 게임마다 목표·움직이는 법·특별 규칙·요령 (내용은 `static/js/board/howto.js`)
- **📖 따라하기**: 다섯 줄 만들기 → 4 막기 → 열린 3 막기 → 열린 4 → 4·3 공격 → 3·3 금지 → 6목 (7과)
- **장기**: 대한장기협회 규칙(빅장 없음). 시작하면 초 → 한 순서로 **상차림**(마·상 자리 4가지)을 골라요.
  장군이면 "장군!", 피하면 "멍군!" 이 떠요. 외통이면 승리, 200수가 넘거나 100수 동안 잡기가 없으면 남은 말 점수로 승부
  (차13 포7 마5 상3 사3 졸2, 한 +1.5). 둘 수가 없으면 [한 수 쉬기]. 말을 누르면 그 말이 움직이는 법이 위에 잠깐 떠요.
  **📖 따라하기**: 차 → 포 → 마 → 상 → 졸 → 장군·멍군 → 외통수 (7과)
- **바둑 9줄 · 13줄**: 중국식 계가(살아 있는 돌 + 둘러싼 빈 곳), 백 덤 6.5집, 자충수·패 바로 되따내기 금지.
  둘 다 **✋ 패스** 하면 끝나고, 죽은 돌은 컴퓨터가 끝까지 대신 둬 보고(몬테카를로) 판단해서 집을 자동으로 세요.
  9줄은 한 번 누르면 바로, 13줄은 두 번 눌러서 둬요. AI 는 몬테카를로 나무 탐색(MCTS + RAVE)이에요.
  **📖 따라하기**(9줄): 따내기 → 단수 도망 → 여러 돌 따내기 → 두 눈 → 패 → 집 짓고 끝내기 (6과)
- **체스**: 국제 규칙 그대로 (캐슬링·앙파상·승진 때 말 고르기, 스테일메이트·50수·3회 반복·말 부족 비김).
  말 그림은 Colin M.L. Burnett 의 'cburnett' 세트 (GPLv2+ / CC BY-SA 3.0)
- 장기·체스 AI 는 전용 엔진(알파베타 + 정지 탐색 + 같은 판 기억표)이라 4·5단계는 꽤 세요
- **오델로**(8×8, 둘 곳 없으면 자동 패스) · **사목**(7×6, 칸에 넣으면 아래로) · **체커**(영국식, 잡기 의무·연속 잡기·왕)
- **만칼라**(칼라: 6구멍×4알, 한 번 더·잡기) · **점 잇기 상자**(4×4 상자, 네 번째 선이면 한 번 더)
- **고누 2종** (지역마다 규칙이 달라 '우리 집 규칙'): **네밭고누**(4×4 판에 말 8개씩 가득, 옆의 내 말을 넘어 그 너머 상대 말 잡기,
  첫 수는 꼭 잡기, 상대를 1개로 줄이거나 가두면 승리, 잡기 없이 40수면 무승부),
  **참고누**(곤질고누: 말 12개 놓기 → 옮기기, 3개 이으면 '꼰'으로 잡기, 놓을 때 잡은 자리엔 말뚝)
- 헥스·우물고누·호박고누는 빠졌어요 (비기기만 하거나 너무 어려워서). 명예의 전당의 옛 기록은 그대로 남아요

### 카드게임관

대기실 **카드게임** 모드. 카드는 서버가 섞어요 (패가 있는 게임은 각자 자기 패만 받아요).
- **프리첼**: 방 안 모두가 **같은 판**(마이크로소프트 프리첼 1~32000번 판, 풀 수 없는 11982번 제외)을 동시에 풀어요.
  카드를 누르면 가장 좋은 곳으로, 끌면 원하는 곳으로. 필요 없는 카드는 홈으로 저절로. 되돌리기·처음부터·포기.
  다 푼 시간은 서버 시계로 재고, 기록실 Top 10 은 빠른 순서 (20분이 지나면 시합 끝)
- 트럼프 카드 그림은 `static/js/cards/kit.js` 에서 직접 그려요 (무늬도 그림이라 폰에서 이모지로 바뀌지 않아요)
- **텍사스 홀덤** (2~8명, 빈자리는 AI): 칩만 써요(진짜 돈 없음). 처음 1000칩, 블라인드 10/20 에서 5판마다 올라요.
  마지막까지 남으면 우승 (사람이 모두 탈락해도 끝). 차례마다 30초. 쇼다운 때 이긴 5장이 반짝여요.
  AI: 끝까지 대신 펼쳐 보는 승률 계산(몬테카를로) + 팟 오즈. 4·5단계는 상대가 들어온 모습으로 상대 패를 짐작해요
- **훌라** (2~4명, 전투 훌라): 7장씩, 세트·런·7 등록, 붙이기(내가 먼저 등록한 뒤), 누가 버린 카드로 바로 등록할 수 있으면
  차례가 아니어도 [땡큐!] (먼저 누른 사람), 한 번에 다 털면 훌라(2배), 스톱(2명 5점·3명 10점·4명 15점 이하, 실패하면 스톱박 2배). 5판 합계
- 서버 쪽 카드 규칙은 `cardgames/` (holdem.py · hulla.py), 각자에게는 자기 패만 보내요 (`cview`)
- **맞고·고스톱** (2명 맞고 7점 · 3명 고스톱 3점 · 4명은 판마다 한 명씩 광 팔고 쉬기): 쪽·뻑·따닥·싹쓸이·뻑 먹기(피 뺏기),

## 게임·내용 추가하는 법

**오락실 미니게임 하나 더**
1. `static/js/games/arcade/<id>.js` 를 만들어요 (비슷한 게임 파일을 복사해서 시작하면 편해요).
   파일 끝에서 `G.register(게임)` 으로 등록하고, 공통 도구는 `const { rng, el, HEX … } = G.kit;` 로 꺼내 써요.
2. `static/games.json` 의 `"arcade"` 에 `{ "id": "<id>", "dur": 30, "name": "게임 이름" }` 한 줄 추가.
3. 끝. 서버 수정, `index.html` 수정, `?v=` 버전 올리기 모두 필요 없어요 (서버가 파일 내용으로 버전을 붙여요).

**과학관 게임 하나 더** — 위와 같고 폴더만 `games/edu/`, 목록은 `"edu"`. 게임 정의에 `edu: true`, `levels`, `hall` 을 넣어요.

**음악관 곡 하나 더** — `js/data/songs.js` 의 `HALL` 에 곡을 넣고 `games.json` 의 `"songs"` 에 id 추가.
저작권이 끝난 곡(작곡가 사후 70년 지난 클래식, 옛 동요)만 넣어요.

**보드게임 하나 더** — `static/js/board/<id>/` 폴더에 `rules.js`(규칙, DOM 없이) · `view.js`(화면 + `Boards.register`) · `ai.js`(AI, 워커에서 실행) · `guide.js`(따라하기, 선택) 를 만들고,
`games.json` 의 `"board"` 에 `{"id": "<id>", "name": "이름", "players": [2, 2], "ai": true, "files": ["rules", "view", "guide"]}` 추가.

**새 데이터 파일** (문제 은행, 연표 등) — `js/data/` 에 만들고 `games.json` 의 `scripts.before` 에 경로 추가.

게임은 모두 서버가 준 같은 `seed` 로 같은 문제를 만들어야 해요 (`Math.random` 대신 `rng(ctx.seed)`).

### 놀이마당

대기실 **놀이마당** 모드 — 여럿이 함께 하는 게임. 카드게임관과 같은 틀(서버가 규칙 계산, 각자에게 자기 화면만)이고
게임 규칙은 `partygames/`, 화면은 `static/js/party/<게임>/`. games.json 의 `"party"` 묶음, `"options"` 로 방장이 고르는 설정.
- **라이어 게임** (3~8명, 바보 모드): 한 명만 비슷한 다른 제시어(기린↔얼룩말)를 받아 자기가 라이어인 줄 몰라요.
  설명 방식: 🗣 모여서 말로([다 말했어요]) · ✍ 떨어져서 글로(한 줄 30자, 제시어를 그대로 쓰면 막기, 나쁜 말은 ♡).
  두 바퀴 설명 → 토론 60초(글로면 채팅) → 투표(동점이면 한 번 더) → 잡힌 라이어는 보기 8개에서 진짜 제시어 맞히기.
  점수: 잡고 못 맞히면 나머지 +1 · 안 잡히거나 맞히면 라이어 +3. 주제 8가지 × 헷갈리는 짝 20개 (`partygames/liar_words.py`)
- **텔레스트레이션** (3~8명, 그림 전달): 각자 공책 한 권(제시어). 그리기 → 옆 사람이 글로 맞히기 → 다시 그리기 … 사람 수만큼.
  그리기: 손가락으로(색 9가지·굵기 3·지우개·되돌리기), 시간이 다 되면 그린 데까지 저절로 보내요. 그리는 시간 45/60/90초.
  다 돌면 공책을 한 장씩 [다음 ▶](누구나)으로 펼쳐 보고 ♥. 점수: 받은 ♥ + 마지막 답이 처음 제시어와 같으면 참여한 모두 +2.
  그림은 선 모음 [색, 굵기, x, y, …] (0~1000 좌표)으로 서버에 보내요 (`partygames/tele.py`)
- **윷놀이** (2~4명, AI 5단계): 바깥 20칸 + 지름길(모·뒷모·방에 멈추면), 참먹이에 정확히 멈추면 다음에 나기.
  윷가락 4개(평평한 면 0.6, 빽도 표시 1개): 도·개·걸·윷·모·빽도. 윷·모·잡기는 한 번 더, 결과를 모아 원하는 말에. 업기·잡기.
  말 수 4/3/2개. AI: 많이 가기·잡기·업기·지름길 + (3단계부터) 잡힐 위험 피하기 (`partygames/yut.py`)
- **할리갈리** (2~6명, AI 5단계, 보드게임관 목록에도 바로가기): 딸기·바나나·레몬·포도 56장. 차례대로 펼치고, 같은 과일이 딱 5개면 종을 먼저 친 사람이
  펼친 카드를 모두 가져가요. 틀리면 한 장씩 나눠 주기. 2/3/5분, 카드가 가장 많은 사람이 1등. AI 종 치는 빠르기 1단계 1.6~2.6초 … 5단계 0.45~0.7초
- **뱀과 사다리** (2~6명, AI): 10×10 판, 사다리 9개·뱀 10개(고전 배치), 100칸에 딱 맞게 도착(넘치면 되돌아감), 6이면 한 번 더(설정)
- **바다 대결** (배틀십, 2명 · 사람끼리/AI): 8×8 바다, 배 5척(4·3·3·2·2칸, 서로 안 붙게), [다시 섞기]로 배치, 맞히면 한 번 더(설정).
  AI: 1 아무 데나 · 2 맞힌 곳 주변 · 3 + 바둑판 무늬 · 4·5 남은 배가 놓일 수 있는 자리 세기 (평균 60 → 34발)
- **다이아몬드 게임** (2~3명, AI): 별 모양 121칸, 말 10개, 한 칸 걷기·뛰어넘기(이어서), 맞은편 진영을 먼저 다 채우면 승리.
  내 진영이 늘 아래로 오게 판을 돌려서 보여 줘요. AI: 목표 꼭짓점까지 거리 합 + (4·5단계) 내 다음 수까지
- **알까기** (2명, AI): 바둑판 100×100, 돌 8/5/3알, 내 돌을 누르고 뒤로 당겼다 놓기(새총), 판 밖으로 나가면 빠짐, 상대 돌을 떨어뜨리고 내 돌이 남으면 한 번 더.

  AI: 상대 돌 쪽으로 여러 방법을 미리 계산해 보고 고르기, 단계가 낮을수록 손 떨림
- **컬링** (2~4명, 두 팀: 1·3번 빨강 / 2·4번 파랑, AI): 얼음판 30×100, 엔드마다 팀당 4개, 휘기(↺·곧게·↻), 호그 라인 못 넘으면 빠짐,
