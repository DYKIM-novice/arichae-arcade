## ★ 최우선: 배경음악 (BGM) 계획

### 왜 맨 먼저
게임의 '싸 보임'은 그림보다 **소리**가 더 크게 만든다. 지금은 `fx.js` 의 `bgmTick()` 이 0.56초마다 오음 음계에서 **무작위 음**을 하나 치는 정도라 곡이 아니고, 기본값이 꺼짐(`settings.bgm: false`)이다. 그림 크레딧이 들지 않으므로 마을 짓기보다 먼저 넣는다(1단계).

### 방식: WebAudio 로 직접 연주하는 작은 '악보 재생기' (내려받기·저작권 없음)
`static/js/merge/music.js` (새 파일) — `fx.js` 의 `ac`·`bgmBus` 를 그대로 받아 쓴다.

1. **악기 4개 (합성음)**
   - **가야금 뜯기**: Karplus-Strong(짧은 잡음 → 지연선 되먹임 + 낮은 통과 필터) 또는 삼각파 + 빠른 감쇠 + 살짝 음 끌어올림(농현 느낌, 50ms 동안 +20cent→0).
   - **대금/소금 같은 피리**: 사인파 + 약한 숨소리(대역 통과한 잡음 5%) + 느린 떨림(비브라토 5Hz, ±8cent), 부드러운 시작(80ms).
   - **해금 같은 긴 음**(선택, 6지역·밤용): 톱니파 → 낮은 통과 필터 1.2kHz, 느린 시작·끝.
   - **작은 북·나무 소리**: 장구 '쿵'(사인 120→60Hz 짧게) · '딱'(잡음 고역 통과 30ms) · 목탁 같은 나무(사인 800Hz 짧게). 아주 작게.
   - 공통: 짧은 **잔향**(ConvolverNode, 잡음으로 만든 1.5초 임펄스 — 파일 없음) 을 버스에 걸어 '방 안 소리'를 없앤다.
2. **악보 형식** (데이터, `data.js` 의 `MUSIC` 에 둔다)
   ```
   { id:'harbor_day', bpm:84, bars:16, scale:'C 궁조(도레미솔라)',
     chords:['C','Am','F','G', …],              // 마디마다 낮은 음(가야금 저음 2음)
     melody:'E4 . G4 A4 | C5 - A4 . | …',      // 8분음 칸, '.' 쉼, '-' 늘임
     counter:'…', drums:'k . t . k k t .',      // 반복 무늬
     inst:{ melody:'flute', counter:'gayageum', bass:'gayageum_low' } }
   ```
   - 재생기는 **미리 0.2초 앞까지 예약**(lookahead 스케줄러, `setInterval(25ms)` + `ac.currentTime` 기준) → 휴대폰에서도 박자가 흔들리지 않음.
   - 같은 곡 반복이 지루하지 않게: 2번째 반복부터 **변주 규칙**(가끔 음 하나를 이웃 오음으로, 꾸밈음 추가, 북 무늬 A/B 교대) — 무작위지만 씨앗 고정.
3. **곡 목록 (직접 작곡, 각 16~32마디 반복)** — 모두 오음 음계(궁·우조), 밝고 느긋하게
   | id | 쓰는 곳 | 느낌 |
   |---|---|---|
   | `title` | 첫 화면 | 가야금 독주, 아르페지오, 76bpm |
   | `board_day` | 판(머지) 화면 낮 | 피리 선율 + 가야금 반주 + 작은 북, 88bpm, 집중 방해 안 되게 음역 좁게 |
   | `board_night` | 판 화면 밤 | 같은 화성, 북 빼고 해금 긴 음, 72bpm |
   | `town_r1`~`town_r6` | 마을 지도, 지금 보고 있는 지역 | 같은 뼈대에 지역별 색: 1 한옥(가야금 중심) · 2 포구(뱃노래 같은 6/8) · 3 골목(통통 튀는 목탁) · 4 정원(피리 길게) · 5 해변 축제(북·꽹과리 작게, 빠름) · 6 등대(해금·잔잔) |
   | `story` | 이야기 장면 | 가야금 + 피리 느린 곡, 감정 장면용 |
   | `event` | 주간 이벤트 화면 | 밝은 축제 변주 |
   | 짧은 징글 4개 | 지역 완성 · 건물 완성 · 엔딩 · 출석 | 2~4초 |
   → 마을 지도는 **화면 가운데 지역**이 바뀌면 그 지역 곡으로.
4. **부드러운 전환**: 곡마다 자기 GainNode. 바뀔 때 1.5초 교차 페이드, **박자에 맞춰** 다음 마디 첫 박에서 시작.
5. **효과음 아래로 낮추기(덕킹)**: 합치기·주문 완료·건물 완성 소리가 나면 bgm 버스를 0.12초 동안 -6dB 로 내렸다가 0.6초에 걸쳐 복귀. 이야기 대사창이 열리면 -4dB.
6. **켜기 규칙**: 브라우저는 소리 자동 재생을 막으므로, **첫 톡(아무 데나)** 에서 `ac.resume()` + 2초 페이드인으로 시작. 기본값 `bgm: true` (기존 저장은 §A.8 에서 한 번만 켜 줌 — 사용자가 일부러 끈 적 있으면 존중: `settings.bgmAsked` 로 구분).
   탭이 숨겨지면 `ac.suspend()`, 돌아오면 `resume()`.
7. **설정**: 배경음 켜기/끄기, **배경음 크기 슬라이더**(0~100, 지금 3단계 대신), 효과음 크기 따로, "조용한 밤 모드"(밤 곡만).
8. **음이 너무 날카롭지 않게**: 마스터에 낮은 통과 7kHz + 컴프레서(이미 있음). 휴대폰 스피커 기준 시험.

### 대안 (주인 허락 필요)
CC0(퍼블릭 도메인) 국악풍 반복 곡 파일(ogg/mp3, 곡당 1~3MB)이 실제 녹음이라 소리가 더 풍성할 수 있다.
다만 ① 동양풍·귀여운 CC0 곡이 드물고 ② 내려받기가 필요하므로 **주인 허락 후에만**. 추천: **직접 연주 방식으로 먼저 만들고**, 아내가 듣고 "부족하다"면 그때 CC0 파일을 찾아 후보(파일명·출처·크기)를 보여 드리고 고른다. 둘 다 같은 `music.js` 의 `play(id)` 뒤에 숨겨 바꿔 끼울 수 있게 만든다.

### 효과음도 같이 손보기
지금 효과음도 단순 사인파. 같은 악기(가야금 뜯기·목탁·작은 종)로 다시 만든다:
합치기(단계가 높을수록 한 음씩 위 — 오음 음계 사다리), 발생기 톡(목탁 '똑'), 주문 완료(가야금 3음 올림 + 엽전 짤랑), 별 획득(작은 종), 망치(나무 '딱딱딱'), 건물 등장(징 작게 + 반짝 종), 모래더미 벗겨짐(사르륵 잡음).

## A. 마을 짓기 설계

### A.1 화면 구성 (휴대폰 세로 우선)
- 하단 버튼 「마을」 → **섬 지도 화면**. 지도는 화면보다 훨씬 크고, **한 손가락 끌기 = 이동**, **두 손가락 벌리기/모으기 = 확대(0.5×~1.6×)**, PC 는 끌기 + 휠. 관성 미끄러짐, 가장자리 탄성.
- 위: 별·동전·소라별 / 아래: [판으로] [꾸미기] [도감] [작업 목록 ▲].
- **작업 목록**(아래 서랍): 지금 할 수 있는 작업 2개 + 다음 작업 미리보기. 누르면 카메라가 그 자리로 날아가고 그 자리에 **별 가격 말풍선 + [짓기]**.
- 지도 위 빈 터에는 **"여기에 지을 수 있어요" 표시**(점선 원 + 깜빡이는 망치 아이콘, 코드로 그림).
- 아직 안 열린 지역: **안개/구름**(코드로 그린 반투명 흰 덩어리, 천천히 흐름) + 자물쇠 + "○지역을 다 고치면 열려요".

### A.2 지도 구조
- 세계 크기 **3072 × 3072 px**(배율 1 기준) = 지역 바탕 그림 6장(각 **1536 × 1024**)을 **2열 × 3행**으로 붙임.
  ```
  [r6 등대곶   ][r5 반짝 해변 ]   ← 위(북)
  [r3 바람골목 ][r4 매화언덕  ]
  [r1 바다별채 ][r2 몽돌 선착장]   ← 아래(남, 시작)
  ```
  처음엔 r1 가운데에서 시작, 지역이 열릴수록 위로 올라가는 진행감.
- **이음매 숨기기**: 바탕 그림 프롬프트에 "가장자리는 바다·숲·돌담·절벽으로 끝남"을 넣고, 경계 위에 나무·바위 스프라이트를 코드로 몇 개 얹고, 경계 64px 를 서로 겹쳐 부드러운 마스크로 섞는다. 지도 바깥은 코드로 그린 바다(그라데이션 + 반짝 물결 무늬 천천히 이동).
- **그리기**: `<canvas>` 1장(devicePixelRatio 반영, 최대 2배). 매 프레임 = 바다 → 바탕 6장(보이는 것만) → 스프라이트를 **발밑 y 순서**로 정렬해 그림 → 걷는 사람 → 밤 덮개·불빛 → 안개. 숨은 비밀·말풍선·버튼은 캔버스 위 DOM 으로 얹음(지금 `town.js` 방식 재사용).
- **좌표는 모두 '세계 px'**, 스프라이트는 **발밑 앵커**(그림 아래 가운데 기준 `ax, ay` 비율) 로 놓는다.
- 그림 크기: 화면에 쓰는 webp 는 바탕 1536×1024(약 250~400KB), 건물 최대 512px, 장식 256~384px. 지역이 열릴 때만 그 지역 그림을 불러 처음 로딩을 가볍게.
- 톡 판정: 스프라이트의 **알파값**(작은 판정용 축소본을 미리 만들어 둠)으로 — 투명한 곳을 눌러도 뒤의 것이 눌리게.

### A.3 작업 → 짓기 (작업 종류 3가지)
| 종류 | 뜻 | 그림 | 예 |
|---|---|---|---|
| **B3 건물** | 새로 짓거나 고침. 완성 후 **모양 3가지 중 고르기** | 변형 3장 | 대문, 본채, 정자 |
| **D1 장식** | 작은 물건을 놓음. 모양 1가지 | 1장 | 석등, 평상, 그네 |
| **G 땅 고치기** | 잔해·잡초·쓰레기 치우기, 길 내기 | 공용 잔해 그림을 **없앰** (바탕 그림에는 깨끗한 땅이 이미 있음) | 돌길, 잡초밭, 모래사장 |

**짓기 연출 (모든 B3/D1, 약 2.2초, 톡하면 건너뛰기)**
1. 별 날아감: 위 별 숫자에서 별 3~5개가 그 자리로 포물선 비행 (0.4초).
2. 잔해 사라짐: 그 터의 잔해 스프라이트가 흔들 → 먼지 구름(코드 입자) 퍼지며 사라짐.
3. **비계**(공용 스프라이트, 건물 크기에 맞춰 늘림)가 아래에서 위로 솟음 → **망치 아이콘 3번 통통**(나무 '딱' 소리 3번) + 먼지 입자 + 화면 살짝 흔들림.
4. 하얀 번쩍 → 건물이 **뿅**(크기 0.6 → 1.12 → 0.96 → 1, 위아래 눌림 효과) + 반짝 별 입자 + 징 소리 + (진동 설정 시) 짧은 진동.
5. B3 이면 **모양 고르기 창**(1개 무료, §F.3 ⑤): 3장 미리보기(좌우 넘기기, 고르는 동안 지도에서 실제 모양이 바뀌어 보임) → [이걸로!]. 안 고르고 닫으면 1번 모양.
6. 이야기 장면(`task.scene`)이 있으면 이어서 재생 — 대사창 뒤 지도에서 그 인물 스프라이트가 건물 앞으로 걸어와 기뻐함(통통 뜀).
- G 작업: 2·4 만 (잔해 흔들 → 먼지 → 사라짐 → 땅 반짝). 길이면 길 위로 반짝임이 한 줄로 흘러감.
- 지역 완성: 카메라가 지역 전체로 물러남 → 모든 건물 차례로 반짝 → 불꽃(코드) → 완성 징글 → 기존 `done.scene` → 안개가 걷히며 다음 지역 공개(카메라 이동).

### A.4 꾸미기 메뉴
- [꾸미기] → 지도가 '편집 상태'(살짝 어두워짐, 지은 건물에 연필 표시).
- 건물 톡 → 모양 바꾸기. 지을 때 고른 1개 + 동전으로 연 모양끼리는 무료·횟수 제한 없음, 안 연 모양은 그 자리에서 동전으로 열기(§F.3 ⑤).
- 장식(출석 7일·이벤트 보상·몽돌 모자) 은 지금처럼 '가진 장식' 줄에서 끌어 **지도 아무 빈 곳**에 놓기 / 다시 거두기. 겹침은 발밑 y 로 자동 정렬.
- (나중) 지역 완성 보상으로 **추가 장식**(벤치·꽃밭·장독대 등 필러 그림 재사용)을 얻어 놓기.

### A.5 살아 있는 마을
- **걷는 사람**: 지역마다 `paths`(세계 좌표 꺾은선 2~4개). 그 지역에 사는 마을 사람(VILLAGERS) 이 지역이 열리면 나타나 길을 따라 걷다 쉬다(2~6초) 함. 걷기 애니는 그림 1장으로 **코드 연출**: 위아래 통통(2px, 걸음 주기 0.4초) + 좌우 방향은 **가로 뒤집기**(이 게임 그림은 좌우대칭 정면/3/4 그림이라 뒤집어도 됨 — PixelLab 의 west 규칙과는 무관) + 발밑 그림자 타원. 톡하면 멈추고 짧은 말풍선(`thanksLine` 재사용) + 하트.
- **몽돌**: 하윤 근처를 따라다니거나 물가를 뒹굴. 숨은 비밀 가까이 가면 꼬리 흔들기(지금 `mongHint` 재사용).
- **배**: 작은 고깃배 2종이 바다 위에서 사인곡선 출렁(±3px, 회전 ±2°), 가끔 천천히 가로질러 감. `r2_boat` 나룻배도 출렁.
- **물결·바람**: 바다 반짝 무늬 이동, 오색천·풍경·연은 살짝 흔들(스프라이트 회전/기울기).
- **낮·밤**: 기기 시각 기준(6~17시 낮, 17~19 노을, 19~6 밤) + 설정에서 '항상 낮' 가능.
  밤 = 전체에 남색 곱하기 덮개(불투명도 0.45) + 각 스프라이트의 `lights`(등불·창문 위치) 에 **따뜻한 빛 동그라미**(더하기 합성, 살짝 깜빡) + 하늘에 별 몇 개. 노을은 분홍 덮개. 그림은 낮 그림 하나로 해결(밤 그림 추가 없음).
- **등대**: `r6_light` 후 밤마다 회전하는 빛줄기(코드 그라데이션 부채꼴) — 엔딩의 상징.
- **탭 장난감**: 지은 건물을 톡하면 통통 + 그 건물 소리(떡집=절구 쿵, 찻집=찻잔 땡, 등대=종). 처음 톡하면 엽전 1~3개(하루 한 번씩) — 지도를 자주 들여다보게 하는 장치.

### A.8 저장 옮기기 (VERSION 2 → 3)
- `st.tasks`(작업 id → 시각)는 **그대로** = 지은 건물 목록. 그래서 진행이 사라지지 않는다.
- 새 필드: `st.look = { [taskId]: 0|1|2 }`(건물 모양, 없으면 0), `st.cam = { x, y, z }`, `st.settings.bgmAsked`, `st.tapDay = { [taskId]: 'YYYY-MM-DD' }`.
- `placed[id] = { a, x%, y% }` → `{ wx, wy }` 로 변환: `wx = tile.col*1536 + x%*1536/100`, `wy = tile.row*1024 + y%*1024/100`. 화면 밖·바다로 떨어지면 그 지역 가운데 근처 빈 곳으로.
- 이미 지은 건물은 처음 열 때 **"마을이 새 모습이 됐어요!"** 안내 + 지은 건물이 하나씩 뿅 나타나는 짧은 연출(한 번만) + 지은 B3 건물 수만큼 모양 고르기 기회 안내(꾸미기에서 아무 때나).
- `settings.bgm`: 버전 2 저장에서 `bgm:false` 는 기본값이었을 뿐이므로 **한 번만 true 로** 바꾸고 `bgmAsked:true`. 이후 끈 건 존중.
- `deserialize` 에서 모르는 필드 무시·없는 필드 기본값 — 지금 방식 그대로. 서버 저장(`pickSave`) 비교 기준(`tasks`, `area`, `delivered`)도 그대로 유효.
- `tools/merge_test.js` 에 '버전 2 저장 → 3 읽기' 시험 추가.

## F. 상점 (새로 · 가방 속 소라별 가게는 없앰)

### F.1 위치·모양
- 판 화면 아래 줄: **[마을] [가방] [상점] [마을 사람]** — 상점은 엽전 꾸러미 아이콘(기존 `items/cn2` 재사용) + 글자. 오늘 무료 선물이 남았으면 **빨간 점**.
- 가방 화면의 소라별 가게(`BAL.shop`)는 삭제, 그 자리에 "물건 사기는 상점에서" 링크 한 줄. 가방 칸 늘리기도 상점 '도우미' 탭으로 옮김(가방 화면에도 바로가기 버튼 유지).
- 상점은 판 위에 반쯤 덮는 창(판이 살짝 보임), 탭 5개. 산 물건은 **판 빈칸 → 없으면 선물함(`gifts`)** 으로 (지금 `takeGift` 흐름 재사용).
- 돈: **동전이 기본**, 소라별은 특별한 것(무지개 소라·옷 일부·즉시 열기)에만. 현금·광고 없음.

### F.2 가격 배수 m (동전 벌이에 맞춤)
주문 동전 = 판매값 합 × 1.5 (판매값 2^(단계-1)). 하루 30분(주문 12~15장) 기준 대략:
| 지금 지역 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 하루 동전 (대략) | 100 | 200 | 450 | 800 | 1,300 | 2,000+ |
| **m** | 1 | 2 | 4 | 7 | 11 | 16 |
'편의' 물건(도우미·기운·보자기)은 **기본값 × m**, 물건 낱개·가방 칸·옷은 고정값. m 은 `BAL.shopMult` 로 두고 경제 모의 실행(B-17) 뒤 조정.

## G. 자동 합치기 (동전)

### G.1 [자동 합치기] 버튼
- 판 오른쪽 아래 작은 버튼(망치+반짝). 누르면 미리 계산해 **"7번 합쳐요 · 10엽전"** 확인 → [합치기].
- 규칙: 판 위에서 **같은 체인·같은 단계 2개씩** 짝지어 합침. 결과가 또 짝이 되면 이어서(연쇄) — 더 없을 때까지.
- **건드리지 않는 것**: 발생기, 마지막 단계, 모래더미·그물 칸, 가방 속, **지금 주문에 필요한 물건**(주문이 원하는 단계·개수만큼은 남김 — 설정에서 끄기 가능), 사용자가 '고정'(길게 눌러 핀) 한 물건.
- 합칠 때 결과는 두 물건 중 **아래쪽·왼쪽 칸**에. 연출은 짝마다 0.08초 간격으로 차례대로 휙휙(전체 최대 1.5초), 합치기 소리 음계가 올라감.
- 가격 = **m × (3 + 합치는 횟수)**, 최대 m × 25. 예) 1지역 7번 = 10, 4지역 7번 = 70. 0번이면 버튼 흐림("합칠 게 없어요").
- 도감 '처음 발견'·소라별 보상·주문 체크는 손으로 합친 것과 똑같이 줌. (되돌리기는 2026-11-04 에 뺌 · 사기 전 확인 창으로 실수를 막음.)
### G.2 왜 이 가격
손으로 해도 공짜인 일을 '편하게' 하는 값. 1지역 하루 벌이(≈100)의 10% 쯤 = 한 번. 판이 꽉 찼을 때 정리 도구. 편하게 모드에서도 같은 가격(동전은 여전히 의미).
### G.3 [자동 합치기 1분] (도우미)
- 30×m 동전 또는 소라별 3. 60초 동안 **새로 생긴 물건**(발생기·보자기·상점)이 판에 놓이자마자 짝이 있으면 자동으로 합쳐짐(연쇄 포함). 화면 위 모래시계 막대.
- 위 '건드리지 않는 것' 규칙 동일. 1분 동안 합치기 횟수 제한 없음. 앱을 닫으면 멈춤(남은 시간 저장).
### G.4 5개 합치기 보너스와의 관계
- 기본 규칙엔 5개 보너스가 없다(B-20). 나중에 넣을 경우: **손으로** 같은 물건 5개를 모아 합치면 다음 단계 **3개**(2개 + 덤 1).
- 자동 합치기는 **항상 2개씩**만 → 5개면 2개 + 1개 남음, **덤 없음**. 그래서 "직접 모아 5개 합치기"를 할 이유가 남고, 자동 합치기 확인창에 "5개 묶음이 3개 있어요 — 직접 합치면 덤!" 안내와 [5개 묶음은 남기기] 체크(기본 켬).

## H. 하윤·몽돌 꾸미기

### H.1 보이는 곳
선택한 옷은 ① 이야기 대사창 초상 ② 판 화면 말하는 사람 칸 ③ 마을 지도 걷는 하윤 ④ 꾸미기 옷장 미리보기 — 4곳 모두 바뀐다.

### H.2 그림 방식 (현실적인 쪽)
- **옷 한 벌 = 전신 그림 1장** (옷 + 머리 모양 + 소품을 한 세트로). 종이인형처럼 겹치는 방식은 쓰지 않음 — AI 그림은 몸 위치가 매번 달라 겹치면 어긋남.
- 만드는 법: 하윤 기본 초상(`chars/hayun`)을 **Kontext** 에 넣고 "같은 소녀, 전신, 3/4 정면, 크림 배경, ○○ 옷" 으로 편집 → 얼굴이 같게 유지. 768×1024 세로.
- 쓰는 법(그림 1장으로 3곳):
  - 대사창·말하는 칸: 전신 그림에서 **위쪽 55%** 를 잘라 초상으로(데이터에 자르기 상자 `crop:[x,y,w,h]`).
  - 지도: 전신을 높이 120px 정도로 줄여 걷기(§A.5 통통 연출).
  - 표정: 기본 옷만 기존 기쁨·놀람 그림(`hayun_joy`, `hayun_wow`). 다른 옷은 **코드 표정**: 통통 뜀 + 머리 위 말풍선 아이콘(♥ / ! / ♪) + 반짝. (표정 그림까지 옷마다 만들면 3배 비용)
- **몽돌**: 몸 모양이 단순 → 소품만 **겹치기 그림**(Lucid, 투명). `mongdol`, `mongdol_joy`, 걷는 몽돌 3장에 각각 머리 기준점·크기를 데이터로 지정(`anchor:{ face:[x,y,s], joy:[…], walk:[…] }`). 기존 '몽돌 모자'(출석 7일)도 이 방식으로 옮김.

## I. 마을 사람 선물 · 우정

### I.1 선물하기
- 새 버튼 **[마을 사람]**(판 화면) 또는 지도에서 걷는 사람 톡 → **프로필**: 큰 초상, 하트 5칸, 좋아하는 것, 다음 보상, [선물하기].
- [선물하기] → 판·가방의 물건 목록에서 고름(또는 판에서 물건을 프로필 초상 위로 끌어 놓기). 상점의 보자기·꽃바구니 같은 물건도 가능.
- 하루에 **한 사람당 3번**까지(마음 점수 폭주 방지). 주문에 묶인 물건이면 "부탁에 쓸 물건인데 줄까요?" 확인.
- 반응: 기쁨 초상(`_joy`) + 하트가 퐁퐁 + 고맙다는 말(좋아하는 정도별 다른 말) + 효과음. 지도에서 그 사람이 통통 뜀.

### I.2 좋아하는 것과 점수
| 반응 | 조건 | 마음 점수 |
|---|---|---|
| 최애 ♥♥ | 사람마다 정한 물건 2개 (예: 미나 = 꽃 백설기·다과상) | 단계 × 3 + 10 |
| 좋아함 ♥ | 그 사람 체인(`VILLAGERS.chains`) 물건 | 단계 × 2 |
| 보통 | 그 밖 | 단계 × 1 |
- 좋아하는 것은 처음엔 '?' — 선물해 보거나 대화(주문 대사)에서 힌트를 들으면 공개.
- 예시 최애: 준이 = 진주 비녀·자개 보석함 / 미나 = 꽃 백설기·다과상 / 꽃님 = 벚나무 화분·매화 분재 / 도치 = 굴비 엮음·돛 / 강 선생 = 청자 꽃병·등대 렌즈 / 루아 = 연꽃 등·조각보 (확정은 인물 설정 보고 조정).

### I.3 우정 단계와 보상
| 단계 | 누적 점수 | 보상 |
|---|---|---|
| 1 | 10 | 동전 30×m |
| 2 | 35 | 소라별 3 + **고맙다는 편지**(짧은 글, 편지지 화면 — 기존 `ui/secret_letter` 테두리) |
| 3 | 80 | **그 사람 장식**(나중 묶음 그림 6장: 준이 우체통, 미나 떡 수레, 꽃님 꽃 수레, 도치 그물 의자, 강 선생 책 평상, 루아 풍등 기둥) |
| 4 | 150 | **짧은 이야기 장면**(4~6줄, 그 사람과 할머니의 추억) + 큰 보자기 |
| 5 | 250 | **하윤 옷 1벌**(§H.3 '우정 5') + 칭호 "○○의 단짝" |
- 주문 납품도 점수 +2 (선물 없이도 천천히 오름).
- 6명 모두 5단계 → "소라섬 모두의 친구" 칭호 + 무지개 소라 3.
- 그림 추가: 우정 장식 6장(나중 묶음). 편지·장면은 글뿐.

## J. 대사 건너뛰기
- 모든 이야기·대사 장면(지역 열림·작업 장면·이야기 부탁·우정 4단계 장면·엔딩) 오른쪽 위에 **늘 보이는 [건너뛰기 ▶▶]** 버튼.

- 건너뛴 장면은 「할머니의 앨범 · 이야기 다시 보기」에서 다시 볼 수 있음(`st.story` 에 본/건너뜀 표시).

### 3단계 — 3~6지역 + 선물·우정 + 약점 P1
