# 회귀 RPG 1인칭 색 패링: 설계안 (사용자 확인 대기)

이 문서는 2026-10-25에 정리했습니다. 사용자 결정은 세 가지입니다.

- 화면은 **1인칭**입니다.
- 가족 협동은 **나중에** 합니다.
- 색 버튼은 공격·방어·필살 역할에 묶지 않습니다. **공격이 닿는 순간 지정된 색(랜덤)을 누르는 패링**입니다.

## 1. 화면 (세로 폰)

| 위치 | 내용 |
|---|---|
| 위 60% | 적이 정면에서 나를 봅니다. 크게 그리고, 맞으면 뒤로 젖혀지며 찌그러집니다. |
| 가운데 | **판정 원**입니다. 공격 예고가 시작되면 그 색의 고리가 바깥에서 줄어듭니다. 고리가 판정 원에 겹치는 순간이 누를 때입니다. 리듬게임의 접근 원과 같은 방식입니다. |
| 아래 | 체력, 필살 게이지, 회차 배지, 빨강·초록·파랑 버튼입니다. |

- 색맹 배려로 색마다 모양을 같이 씁니다(빨강 ▲, 초록 ●, 파랑 ■). 남자아이의 약 8%가 적록색약입니다.
- 내 모습은 화면 아래의 손이나 무기로만 보입니다. 패링하면 무기가 번쩍이며 막는 컷이 나옵니다.

## 2. 판정 (공격 한 타마다 색 하나)

판정은 둘뿐입니다(사용자 결정: 단순하게, 막기 단계 없음).

| 결과 | 조건 | 효과 |
|---|---|---|
| **패링** | 맞는 색을 판정 시간 안에 누름 (시간 폭은 난이도별, 아래 2-1) | 타격 멈춤 120ms, 슬로 300ms, 흰 번쩍임, "패링!", 자동 반격 ×3, 게이지 +30 |
| **맞음** | 다른 색을 누름, 너무 이르거나 늦음, 또는 안 누름 | 피해를 그대로 받습니다. 다른 색이었으면 "색이 달라요!", 타이밍이 틀렸으면 "빨라요!" 또는 "늦어요!"가 뜹니다. |

- **한 타에는 처음 누른 버튼만 인정합니다.** 세 버튼을 동시에 막 눌러도 패링이 되지 않습니다. 기존 `parryLock` 380ms를 그대로 씁니다.
- 연타 공격(예: 방망이 3연타)은 타마다 색이 따로 나옵니다(예: 빨-파-빨).

### 2-1. 난이도: 없앰 (사용자 결정, 2026-10-25)

> 계속 회귀하면 쉬워지므로 난이도 선택은 두지 않습니다. 판정·콤보 값은 아래 표의 '보통' 열 하나만 씁니다(판정 230ms, 최대 연타 3, 간격 450ms 이상, 예고 1.3초, 엇박 없음, 조각 ×1). 아래 표는 기록으로만 남깁니다.

(폐기된 안)

어려워질수록 콤보가 길어지고, 타이밍을 더 정밀하게 맞춰야 합니다.

| | 쉬움 | 보통 | 어려움 | 헬 |
|---|---|---|---|---|
| 판정 시간 폭 | 300ms | 230ms | 160ms | 110ms |
| 한 공격의 최대 연타 수 | 2 | 3 | 4 | 6 |
| 연타 사이 간격 | 600ms 이상 | 450ms 이상 | 330ms 이상 | 230ms 이상 |
| 고리가 줄어드는 시간 (예고) | 1.6초 | 1.3초 | 1.0초 | 0.75초 |
| 엇박 (간격이 일정하지 않은 콤보) | 없음 | 없음 | 가끔 | 자주 |
| 기억 조각 배율 | ×1 | ×1.2 | ×1.5 | ×2 |

- 적 체력과 공격력은 난이도와 관계없이 같습니다. 어려움은 숫자가 아니라 손으로 느끼게 합니다.
- 회차, 기억 조각, 영구 노드는 난이도와 관계없이 하나로 이어집니다. 첫 클리어 회차와 최고 기록은 난이도별로 따로 저장합니다(올림픽 혼자 연습과 같은 방식).
- 위 숫자는 시작값입니다. 자동 플레이어 시험으로 다듬습니다.

### 2-2. 색 정하는 방식

- 기본은 **매번 랜덤**입니다(사용자 원안).
- 여기에 회귀 보상을 겹칩니다. **지난 회차에 나를 쓰러뜨린 공격은 다음 회차부터 색이 0.4초 먼저 보입니다**("💭기억났다!"). 랜덤이어도 "나는 이 공격을 안다"는 회귀의 맛이 남습니다. 조사 보고서의 킥 포인트 '예지'를 이 방식으로 넣습니다.

## 3. 기존 조작으로 만든 기능 → 바꿀 내용 (빼지 않고 바꿉니다, 확인 필요)

| 기존 (횡스크롤) | 1인칭 색 패링 |
|---|---|
| 빨강 탭 3연타 콤보 | 적이 공격하지 않을 때 **자동 공격**합니다. 3타 리듬과 3번째 큰 타격은 그대로 둡니다. |
| 빨강 꾹 = 모아 베기 | **연속 완벽 패링 3번이면 '강반격'**(×5)입니다. |
| 초록 누르고 있기 = 막기 | 막기는 없어집니다(사용자 결정). 판정은 패링/맞음 둘뿐입니다. |
| 파랑 = 필살기 | 게이지가 다 차면 **세 버튼 동시 누르기**로 씁니다. 연타 5번, 그동안 무적입니다. |
| 공격 틈(`vuln`) 때 마구 때리기 | 큰 공격을 패링한 뒤에 "지금이야!"가 뜨고 자동 공격이 2배 빨라집니다. |
| 뚝딱 내려찍기: 예고 중 많이 때리면 끊김 | 빠른 3색 연속(빨-초-파 순서)으로 바꿉니다. 3번 모두 완벽이면 끊기고 크게 기절합니다. |

**카드(11종)는 모두 남깁니다.** 효과만 새 조작에 맞춥니다.

| 카드 | 바뀐 효과 |
|---|---|
| 연속 베기 | 자동 공격력 +20% |
| 모아 베기 | 강반격 +40%, 필요한 연속 패링 3번 → 2번 |
| 회복 베기 | 3번째 자동타마다 체력 +3 |
| 철벽 가드 | 막기가 없어져서, 맞을 때 받는 피해 -15%로 바꿉니다 (확인 필요) |
| 번개 패링 | 판정 시간 폭 +40ms, 반격 +30% |
| 반격 회복, 필살 충전, 필살 강화, 튼튼 몸, 행운 별, 회복 물약 | 그대로 |

- 영구 노드 '전생의 검술'은 '연속 베기를 배운 채로 시작'으로 그대로 둡니다.
- 카드 고르기(색 버튼 = 카드), 800ms 입력 보호, 다시 뽑기는 그대로입니다.

## 4. 그대로 다시 쓰는 것

- 회귀 연출, 전생 정산, 경험치 배율(1 + 0.33·√(회차−1), 최대 ×4), 기억 조각, 영구 노드 3개, 스킬 기억
- 방 5개 + 도깨비 대왕, 적 3종, 방 깊이에 따른 강해짐
- 타격감: 타격 멈춤, 피해 숫자, 화면 흔들림(상한 있음), 적 찌그러짐
- 계산(`sim.js`)과 그리기(`view.js`)를 나누는 구조. 그리기는 1인칭으로 새로 만듭니다.

## 5. 협동은 나중에

- `net.js`, `rpg.py`, server.py의 RPG 부분은 **지우지 않고 그대로 둡니다.**
- 이번에는 로비에서 '혼자 하기'만 보이게 합니다.
- 협동을 다시 켤 때는 새 판정 규칙을 서버(`rpg.py`)에도 똑같이 맞춥니다.

## 6-1. 출시 단위: 1장 먼저 (사용자 결정, 2026-10-25)

- 1장(숲 스테이지: 방 5개 + 도깨비 대왕)만 먼저 완성해서 배포합니다. 반응이 괜찮으면 2장을 이어서 만듭니다.
- 배포는 지금처럼 스크린샷을 보고 사용자가 OK한 뒤 `main`에 올립니다(Render 자동 배포).
- 1장 배포 묶음: 1단계 규칙 → 1인칭 화면 → 1장 레오나르도 그림 → 한 판 전체 자동 테스트 → 기존 게임 회귀 테스트 → 스크린샷 확인 → 배포

## 7. 진행 순서와 확인 방법

1. `sim.js`와 `data.js`를 색 패링 규칙으로 바꿉니다. node 자동 플레이어로 실력별(연타만, 아이, 중학생, 어른) 클리어까지 걸리는 회차를 숫자로 확인합니다. 목표는 아이 3~5회차, 첫 죽음은 방 3 근처입니다.
2. 1인칭 화면(`view.js`)을 임시 그림으로 만듭니다. 판정 원, 패링 번쩍임, 회귀 연출을 넣습니다.
3. Playwright로 한 판 전체(죽음 → 회귀 → 다음 회차 → 클리어)를 자동으로 돌리고, 스크린샷을 보여드리고 확인받습니다.
4. 기존 게임(오락실, 올림픽 o100, 로비)이 망가지지 않았는지 회귀 테스트를 합니다.
