## 1. 소개

**한 줄**: 폭풍에 무너진 할머니의 한옥 바닷마을로 돌아온 주인공이, 같은 물건 두 개를 합쳐 더 좋은 물건을 만들고
마을 사람들의 부탁을 들어주며 마을을 하나씩 되살리고, 할머니가 숨겨 둔 편지의 비밀을 찾는 이야기.

**제목 후보**
1. 「소라섬 등불 이야기」 (추천 · 등불이 이야기 끝과 이어짐)
2. 「달빛포구 다시 피우기」
3. 「물빛 한옥마을」

**톤**: 따뜻하고 느긋함. 실패·벌칙·시간 압박 없음. 동양풍 동화 같은 바닷마을 — 기와 처마, 창호지 불빛, 돌담, 장독대.
색: 복숭아 분홍·연옥색 바다·크림 한지·연한 쪽빛, 포인트로 단청 빨강·노랑 조금.
갈등은 "무너진 것을 다시 세운다"는 정도로만. 대사는 짧고 다정하게, 한 장면 3~6줄.

## 2. 핵심 반복 (코어 루프)

```
발생기 톡 → 1단계 물건 → 같은 것 2개 끌어 합치기 → 상위 단계
→ 마을 사람 주문 납품 → 동전 + 별 → 별로 복원 작업 → 이야기 진행 → 새 발생기·새 주문
```

### 2.1 판
- **7열 × 9행 = 63칸** (세로 휴대폰). 칸 최소 44px, 화면 폭에 맞춰 늘림.
- 위: 주문 카드 3장(가로 스크롤 최대 5) / 가운데: 판 / 아래: 가방·상점·마을 버튼.
- **덮인 칸**: 처음엔 일부 칸이 '모래더미'로 덮여 있음. 그 옆 칸에서 합치기가 일어나면 1단계 벗겨짐(2번에 열림).
  판 넓히기 진행감을 줌. 지역 복원마다 덮인 칸 몇 줄씩 사라지게 설정 가능.

### 2.2 발생기 (8종, 체인당 1개)
- 톡 하면 그 체인의 1단계(가끔 2단계 10%) 물건이 빈 옆칸에 튀어나옴. **에너지 1** 소모.
- 판이 꽉 차면 "자리가 없어요" 안내만, 에너지 안 씀.
- 발생기 강화(동전, 3단계): 2단계 확률 10→20→30%, 3단계 강화 시 가끔 3단계.
- 일부 발생기는 **충전식**(차·빛): 12번 톡 후 10분 쉼 → 판 균형 조절용.
- 발생기는 지역 복원 이야기에서 하나씩 얻음 (1지역: 조개·떡·꽃 → 이후 하나씩).

### 2.3 에너지
- 최대 **100**, **2분에 1** 회복 (약 3시간 20분에 가득). 앱을 닫아도 시각 기준으로 회복.
- 에너지 병 아이템(합치기 가능), 동전으로 하루 3번 채우기(가격 상승), 일일 보상.
- 설정에 **「편하게 모드」**(에너지 무제한) 켜기/끄기 — 가족 전용이므로 막힘 없이 즐길 수 있게.

### 2.4 합치기 규칙
- 같은 체인·같은 단계 2개 → 다음 단계 1개 (머지-2). 마지막 단계는 더 안 합쳐짐(반짝 테두리).
- 끌어서 놓기 + **톡-톡 합치기**(하나 톡, 같은 것 톡) 둘 다 지원.
- 다른 물건 위에 놓으면 자리 바꾸기. 빈칸이면 이동.
- **무지개 소라**(만능): 아무 물건과 합쳐 그 물건의 다음 단계가 됨.
- 합치기 순간: 짧은 통통 튀는 애니 + 효과음 + 진동(설정). 처음 만든 단계는 "새 발견!" 도감 등록.

### 2.6 가방·판매·되돌리기
- **가방**: 판 밖 보관 칸. 처음 6칸, 동전으로 한 칸씩 늘려 최대 20칸 (가격 50→ 1.4배씩).
- **판매**: 물건을 톡 → 정보창 [팔기] → 동전 (단계 n 이면 대략 2^(n-1)). 마지막 단계·이야기 물건은 팔기 전 확인창.
- **되돌리기**: 마지막 행동 1번(팔기·합치기·이동) 되돌림. 판매는 5초 안 토스트 [되돌리기]로 즉시 복구.
- **도감**: 체인별 단계 칸. 처음 발견 시 소라별 1개.

## 3. 주문

### 3.1 누가 주문하나
- 마을 사람 7명(4.3절) + 지역 손님. 주문 카드 = 얼굴 + 원하는 물건 1~3개 + 보상.
- 판/가방에 해당 물건이 있으면 카드에 초록 체크, [건네기] 버튼 활성.
- **일반 주문**: 해금된 체인에서 자동 생성, 현재 지역 체인 가중치↑. 동시에 3~5장.
- **이야기 주문**: 복원 작업에 필요한 고정 주문 (예: 미나의 첫 꽃 백설기). 금색 테두리, 끝내면 대사.
- 마음에 안 들면 [다른 부탁] 으로 교체 (10분 쿨, 무료).

### 3.2 보상
- 동전 = 납품 물건 판매값 합 × 1.5 (팔기보다 항상 이득).
- 별 = 1 + floor(납품 단계 합 / 4) (이야기 주문은 고정값, 보통 더 많음).
- 가끔(15%) 덤: 식혜·선물 보자기·무지개 소라.

### 3.3 난이도 곡선
| 지역 | 물건 수 | 최고 단계 | 쓰이는 체인 | 주문 1장 별 |
|---|---|---|---|---|
| 1 바다별채 | 1 | 2~4 | A B D | 1~2 |
| 2 선착장 | 1~2 | 3~5 | +E | 1~3 |
| 3 바람골목 | 1~2 | 4~6 | +C F | 2~3 |
| 4 꽃언덕 | 2 | 4~7 | +G | 2~4 |
| 5 반짝 해변 | 2~3 | 5~8 | +H | 3~5 |
| 6 등대곶 | 2~3 | 6~9 | 전부 | 4~6 |

- 지난 주문이 너무 오래(30분 이상) 안 끝나면 다음 생성 주문을 한 단계 낮춤 (막힘 방지).

## 4. 마을 복원 · 이야기

### 4.1 무대
**소라섬**: 남쪽 작은 섬, 한옥 지붕이 바다를 따라 늘어선 마을. 포구 이름은 **물빛포구**. 1년 전 큰 폭풍 '검은 너울' 뒤로 사람들이 떠나 비어 감.
등대가 꺼진 뒤로 배가 잘 안 들어옴.

### 4.2 전체 줄거리
- **시작**: 도시에서 일하던 **하윤**은 돌아가신 할머니 **윤해**의 한옥 민박 「바다별채」를 물려받았다는 편지를 받는다.
  편지 끝에 "섬 곳곳에 내 편지를 숨겨 두었단다. 등대에 다시 불이 켜지는 날, 마지막 편지를 읽으렴."
- **가운데**: 지역을 복원할수록 사람들이 돌아오고, 할머니가 섬 사람 한 명 한 명에게 남긴 인연이 드러난다.
  왜 할머니가 편지를 숨겼는지(사람들이 다시 서로 돕게 하려고) 서서히 알게 된다.
- **끝**: 등대 렌즈를 되살려 불을 켠다. 첫 '등불 바다 축제'(바다에 등불을 띄우는 밤)에 떠났던 사람들이 배를 타고 돌아온다.
  마지막 편지: 할머니가 젊은 시절 이 섬에 처음 왔을 때의 이야기 + "이제 이곳은 네 집이야".
  하윤은 도시로 돌아가지 않고 섬에 남기로 한다. (엔딩 후에도 주문·이벤트는 계속)

## 5. 숨은 비밀 · 일일 보상 · 주간 이벤트 (전부 무료)

### 5.1 숨은 비밀 (마을 화면)
- **할머니의 편지 조각 12장**: 지역마다 2장, 배경 속 작은 반짝임(톡). 일부는 작업 완료 후에만 나타남.

## 6. 저장 · 오프라인 · 설정 · 접근성

### 6.1 저장
- **기기 저장**: `localStorage['arichae_merge_v1']` (판·가방·에너지 시각·주문·진행·도감·설정). 행동 후 1초 묶어서 자동 저장. `v` 필드로 이전 버전 변환.
- **서버 저장**: PIN 통과한 사람만 `POST /merge/api/save` · `GET /merge/api/load` (7절 쿠키 필요).

### 6.2 오프라인

## 7. 접근 잠금 (PIN, 서버에서 검사) — **1단계에 포함**

사이트와 저장소가 공개이므로 **클라이언트 JS 로 PIN 을 확인하지 않는다.** 서버가 막는다.

### 7.1 규칙
- PIN 값은 **환경변수 `MERGE_PIN`** (Render 대시보드에서만 설정). 저장소·문서·클라이언트 코드에 PIN 을 절대 쓰지 않는다.
  `MERGE_PIN` 이 없으면 게임 자체가 닫힘(잠금 화면에 "준비 중").
- 쿠키 서명 키 **`MERGE_SECRET`** 도 환경변수 (없으면 서버 시작 때 무작위 생성 → 재시작마다 다시 PIN 입력, 경고 로그).
- 게임 HTML/JS/데이터(이야기·체인 표)는 `static/` 이 아닌 **`merge/`** 폴더(저장소 뿌리)에 두고 서버 경로로만 보냄:
  - `GET /merge` → 쿠키 유효하면 `merge/index.html`, 아니면 **잠금 화면**(숫자 4칸 + 키패드, 게임 내용 없음).
  - `GET /merge/<파일>` → 쿠키 검사 + 허용 목록(.js .json .css .html)만, `..` 차단.
  - `POST /merge/auth` (본문 `{pin}`) → `hmac.compare_digest` 로 비교 → 맞으면 쿠키 발급.
  - `/merge/api/*` (저장) 도 같은 쿠키 필요, 아니면 401.
- **쿠키** `merge_auth = <만료시각>.<HMAC-SHA256(MERGE_SECRET, "merge|"+만료시각)>`
  `HttpOnly; Secure; SameSite=Strict; Path=/merge; Max-Age=15552000` (180일). JS 에서 읽을 수 없음.
- **틀린 시도 제한**: IP 당 10분에 5번 (Render 는 `X-Forwarded-For` 첫 값), 넘으면 10분 잠금 + 남은 시간 표시.
  추가로 전체 합계 1시간 30번 넘으면 1시간 전체 잠금(흩어진 무작위 시도 방지). 메모리 dict 로 충분.
  응답은 맞음/틀림 외 정보 없음, 틀리면 0.5초 지연.
- **로비**: `games.json` 에 넣지 않음. 대기실에는 작은 **자물쇠 카드**(「비밀 정원」 같은 이름)만 두고 `/merge` 로 이동,
  또는 카드 없이 아내 휴대폰 홈 화면 바로가기만. (추천: 홈 화면 바로가기 + 로비 자물쇠 카드 둘 다)
- `sw.js`·`manifest` 는 그대로, 6.2절처럼 /merge 는 사전 캐시 제외.

### 7.2 감수하는 점 (주인 확인용)
- **그림 파일은 공개 정적 파일**(`static/img/merge/...`)로 둔다. 주소를 알면 누구나 볼 수 있지만 민감도가 낮고,
  쿠키 검사 경로로 그림까지 보내면 캐시·속도 손해가 큼. 원하면 나중에 /merge/img 로 옮길 수 있음.
- **소스 코드와 이야기 글은 공개 저장소에 그대로 보인다.** 잠금이 막는 것은 '사이트에서 플레이하기'와 '아내의 저장 데이터'다.
  이야기까지 숨기려면 이야기 데이터를 비공개 저장소/환경에 두는 별도 작업이 필요(이번 범위 밖, 원하면 말씀).
- 4자리 = 1만 가지. 위 제한이면 한 IP 로 다 맞추는 데 2주 이상, 전체 제한까지 걸려 실제로는 더 김. 더 원하면 6자리로.
